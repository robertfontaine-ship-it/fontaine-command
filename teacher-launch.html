04 • First Five Meetings

Teach the system one layer at a time

Students experience something real every meeting, but no single day carries the whole operating system.

DAY 1

Enter the city

Project orientation. Students create a Mission ID using first name, last initial, and period, then explore City Hall.

Win condition: correct profile + one destination named.
DAY 2

Finish a Quick Mission

Model required work first, specific evidence, receipt creation, and the Canvas handoff.

Win condition: one complete review packet in Canvas.
DAY 3

Open the course path

Students select their course, complete the matching applied mission, and learn the 4-of-5 gate rule.

Win condition: first gate attempted honestly.
DAY 4

Recover like a pro

Practice Switch Profile, autosaved drafts, profile export, and a test restore before stakes are high.

Win condition: students can explain the recovery ladder.
DAY 5

Close the loop

Review packets, approve entries, spotlight strong evidence, and run the first low-dollar weekly drawing.

Win condition: students see that quality and follow-through count.

07 • Shared Devices & Recovery
Protect progress without student accounts

        
The system is browser-local by design. The routine matters as much as the technology.

      

      

        
START
Claim the right profile
  1. Open My Mission ID.
  2. Use first name, last initial, and correct period.
  3. If the device was shared, choose Switch Profile—never type over another student.

        
WORK
Let autosave work
  1. Stay on the assigned profile.
  2. Wait for “All changes saved” before leaving a mission.
  3. Create the review packet only after every response is complete.

        
END
Close the loop
  1. Paste the review packet into Canvas.
  2. Export the Mission ID backup on the assigned backup day.
  3. Use Switch Profile or close the browser—do not reset the device.

        
RECOVER
Use the ladder in order
  1. Refresh and reopen My Mission ID.
  2. Confirm the correct profile is active.
  3. Reopen the mission and check the recovered draft.
  4. Restore the student’s latest backup file.
  5. Use teacher device cleanup only after backup options are exhausted.
